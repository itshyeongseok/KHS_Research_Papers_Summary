Intelligent Finite-Time Formation Control for Flapping Wing Micro Aerial Vehicles
Tier 1 — 중요
Xiaoyan He, Zhaojing Yang, Linke Zhang, Chun Zha
Heliyon, Vol. 9, 2023, e20944 · DOI: 10.1016/j.heliyon.2023.e20944
논문 요약
본 논문은 다수의 날갯짓 초소형 비행체(FWMAV) 군집에 대한 유한 시간 대형 제어(finite-time formation control)를 다룬다. 2차 Euler-Lagrange 동역학을 기반으로 병진·회전 이중 루프 서브시스템으로 분리하고, RBFNN(방사기저함수 신경망)으로 모델 불확실성과 외부 교란을 추정한다. 포텐셜 에너지 함수로 시스템 연결 유지와 충돌 회피를 동시에 달성하며, 실용 Lyapunov 유한 시간 안정성 이론과 Moore-Penrose 일반화 역행렬을 활용하여 정확한 수렴 시간을 계산한다. 8기 FWMAV 시뮬레이션에서 t = 1.5 s 이내 대형 수렴을 시연한다.

Introduction: 연구 동기 클릭하여 자세히 ▸
FWMAV는 곤충·새와 유사한 수직 이착륙·저속 기동 특성을 갖추어 군사·민간 응용 잠재력이 크지만, 다수 FWMAV 군집의 대형 제어는 비선형 동역학·외부 교란·연결 유지·충돌 회피를 동시에 다루어야 하는 난제이다. 기존 연구는 정확한 수렴 시간 계산 미비, 연결 유지·충돌 회피 미고려, 병진-회전 결합 특성 무시 등의 한계를 보인다. 본 논문은 Euler-Lagrange 모델 기반의 지능적 유한 시간 대형 제어로 네 가지 제어 목표(불확실성 추정, 충돌 회피, 연결 유지, 유한 시간 수렴)를 동시에 달성한다.
Related Works: 관련 연구 클릭하여 자세히 ▸
FWMAV 대형 제어는 쿼드로터·UAV 대형 제어의 확장으로 연구되어 왔으나, Euler-Lagrange 기반 병진-회전 결합 모델에서의 유한 시간 수렴·연결 유지·충돌 회피를 동시에 다룬 연구는 부재하다. 관련 이론(포텐셜 함수, RBFNN, 슬라이딩 모드, 실용 Lyapunov)은 각각 개별적으로 활용되었으나 본 논문이 이를 통합하는 최초 시도이다.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
2차 Euler-Lagrange 동역학으로 FWMAV의 병진·회전을 모델링하고, 모델 불확실성과 외부 교란을 포함한 일반 운동 방정식을 수립한다. 이중 루프 구조로 병진(외부)·회전(내부) 서브시스템을 분리하여 각각에 제어 프로토콜을 설계한다. RBFNN으로 미지 비선형 함수를 근사하고, 포텐셜 에너지 함수로 감지 반경 기반 연결 유지·충돌 회피를 달성하며, 실용 Lyapunov 유한 시간 안정성과 Moore-Penrose 일반화 역행렬로 정확한 수렴 시간을 계산한다.
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
8기 FWMAV + 가상 리더의 MATLAB 수치 시뮬레이션으로 제안 제어 법칙을 검증한다. 연결 무방향 통신 토폴로지 하에서 분산 추정기 파라미터 (β₁ = [0.5, 0.5]^T, β₂ = [2, 2]^T), 제어 게인 (k₁ᵢ = 0.43, k₂ᵢ = 0.25, k₃ᵢ = 0.3, k₄ᵢ = 0.5), 감지 반경 (r_coll = 0.2, r_joint = 3, r_conn = 10) 등을 설정. 위치 궤적·제어 입력·속도 상태를 통해 t = 1.5 s 이내 대형 수렴, 연결 유지, 충돌 미발생을 확인한다.
Discussion: 결과의 해석 클릭하여 자세히 ▸
제안 방법은 기존 FWMAV 대형 제어 대비 네 가지 제어 목표의 동시 달성이라는 차별점을 가진다. 포텐셜 에너지 함수의 단일 함수 설계로 연결 유지·충돌 회피를 통합 처리하여 기존의 복잡한 조건·제어 로직을 단순화했다. 실용 Lyapunov 이론을 통해 고전적 방법 대비 정확한 수렴 시간 계산이 용이해졌다. 한계로 시뮬레이션 기체 수가 적고 파라미터 선택에 실험적 근거가 부족하며, 향후 강화학습 기반 최적화 제약 적용이 제안된다.
Conclusion: 최종 요약 클릭하여 자세히 ▸
다수 FWMAV의 2차 Euler-Lagrange 동역학을 병진·회전 서브시스템으로 분리하고, RBFNN 적응 추정으로 불확실성·외부 교란을 효과적으로 추정하며, 포텐셜 에너지 함수로 충돌 회피·연결 유지를, 실용 Lyapunov 유한 시간 이론으로 정확한 수렴 시간을 보장하는 지능적 대형 제어 프레임워크를 제시한다. 8기 FWMAV 시뮬레이션으로 제어 법칙의 유효성과 우수성을 검증한다.
