Autonomous Formation Flight Control of Large-Sized Flapping-Wing Flying Robots Based on Leader–Follower Strategy
Tier 0 — 핵심
Hui Xu, Yuanpeng Wang, Erzhen Pan, Wenfu Xu, Dong Xue
Journal of Bionic Engineering, Vol. 20, 2023, pp. 2542–2558 · DOI: 10.1007/s42235-023-00402-5
논문 요약
본 논문은 대형 날갯짓 비행 로봇(LFWFR)을 위한 최초의 자율 leader–follower formation 비행 제어기를 제안하고, HIT-Phoenix 2대(2.3 m wingspan, 675 g, 3–5 Hz 날갯짓)에서 야외 검증. 운동학 모델이 description matrix $C$로 formation 기하를 표현하고, consensus law가 각 follower의 yaw·속도·고도를 leader + 원하는 상대 거리·위상에 수렴시킴. 핵심 신규성은 변속기에 부착한 Hall 센서로 3 flapping cycle 평균 비행 상태를 산출하는 flapping-period-aware navigation method — overshoot·stall을 유발하는 2–5° pitch 변동을 억제. 직선·원형·전환 3가지 formation 모드를 시뮬레이션에서 구현하고, GPS noise·무선 dropout·꼬리 roll/pitch coupling 환경에서 야외 비행으로 검증. 구체 수치, 하드웨어(STM32F405 + AS14B-TTL + DMA + FreeRTOS), 프로토콜 프레임 레이아웃을 공개하여 사용자의 향후 multi-FWAV 임무에 직접 차용 가능한 레시피.

Introduction — 연구 동기 클릭하여 자세히 ▸
새는 에너지 절감·항속거리 확장 위해 formation 비행 사용; 저자들은 이 아이디어를 대형 날갯짓 비행 로봇(LFWFR)에 적용. 동기는 단일 LFWFR이 야외 임무에 필요한 항속/시간/신뢰성 기준 미달 + 날개 무게 + 공력 중심 결합으로 기존 고정익·회전익 formation 알고리즘이 부적합. 기여는 LFWFR용 최초 자율 leader-follower formation 비행 제어기, HIT-Phoenix 플랫폼에서 야외 검증.
Related Works — 관련 연구 클릭하여 자세히 ▸
기존 FWFR 연구는 prototype 설계 (Robobee·Delfly·Robo Raven·Dove·FMAV·USTBird·HIT-Phoenix)와 formation 분석으로 분리. Prototype 작업은 대부분 자율 formation 미달; FWFR formation 작업은 실내 시연 또는 이론/시뮬레이션에 머무름. 전통 formation 알고리즘 — leader-follower·virtual structure·artificial potential field·behavior-based — 은 LFWFR이 제공 가능한 것보다 훨씬 정확한 궤적 추적을 가진 고정익·회전익 플랫폼용으로 개발 → 새 periodic-flight-aware 접근법 동기 부여.
Method — 새로운 접근 방법 클릭하여 자세히 ▸
운동학 모델은 yaw-pitch-roll Euler 시퀀스의 측지·body-fixed 좌표계 사용; 공력 $F_L, F_T$와 중력 $G$가 LFWFR별 동역학 정의. Formation 기술 행렬 $C$가 각 follower에 대한 desired 상대 거리 $\rho$와 위상각 $\gamma$ 인코딩; LFWFR $i,j$ 간 상대 기하가 $\dot\rho_{ij}, \dot\gamma_{ij}, \dot\psi_{ij}$ 산출. Yaw·속도·고도 일관성 법칙이 각 follower를 leader + $\rho^d_{ij}$와 $\gamma^d_{ij}$에 의존하는 추가 spacing 항을 추적하도록 구동. 하드웨어: STM32F405RGT6 + Cortex-M4 + FPU + AS14B-TTL 무선 + DMA + FreeRTOS + 커스텀 31-byte 통신 프레임 (SOH/data/EOT/check). Flapping-period-aware navigation 방법은 변속기에 Hall 센서로 상승 엣지 검출, 3 flapping cycle 평균 비행 상태로 2-5° pitch 변동 억제.
Experiment — 실험 방법과 결과 클릭하여 자세히 ▸
시뮬레이션이 3개 formation 모드 검증 — 직선(Table 3, $t=20$ s)·원형(Table 4, $t=20$ s)·전환(Table 5, $t=40$ s, leader가 $\pi/4$에서 $5\pi/4$로 pivot 후 formation이 대각선으로 전환). Follower가 ~5 s 내에 leader의 yaw·속도·고도 추적, 오차는 ±1 m 내 변동. 야외 실험은 안전 고도 위 이륙 후 2대 HIT-Phoenix LFWFR을 10 m 간격 + $3\pi/4$ 위상으로 사용. Flapping-period-aware navigation이 50 Hz raw 샘플링 대비 pitch 변동을 가시적으로 감소; formation 알고리즘이 GPS 오차·무선 dropout·꼬리 roll/pitch 결합에도 야외 formation 예비 실현.
Discussion — 결과의 해석 클릭하여 자세히 ▸
본 논문은 LFWFR formation 비행 갭을 실험적으로 닫음, but 여러 실용 bottleneck 가시 — GPS 정밀도·무선 신뢰성·flapping 주파수-속도 비선형성·꼬리 roll/pitch 결합·미성숙 이착륙. Flapping-period-aware navigation 방법이 가장 이전 가능한 단일 기여: 단순 Hall 센서 + 3-cycle 평균 trick으로 날갯짓 사용하는 모든 FWAV에 채택 가능. 통신 프로토콜 설계와 STM32F405 + AS14B-TTL 하드웨어 레시피는 출판급 reference 설계. 고도가 다음 frontier.
Conclusion — 최종 요약 클릭하여 자세히 ▸
LFWFR용 leader-follower formation 비행 제어기 제안, 직선/원형/전환 모드 시뮬레이션 검증 + 2대 HIT-Phoenix 로봇 야외 검증. Flapping-period-aware navigation이 동체 변동 흡수. 향후 연구는 3D 궤적 유지 정확도 향상 + 초다수 LFWFR로의 확장에 집중.
