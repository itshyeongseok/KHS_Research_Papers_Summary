Distributed UAV Swarm Formation and Collision Avoidance Strategies Over Fixed and Switching Topologies
Jia Wu, Chunbo Luo, Yang Luo, Ke Li
IEEE Transactions on Cybernetics, Vol. 52, No. 10, 10969–10979 (2022) · DOI: 10.1109/TCYB.2021.3132587
논문 요약
이 논문은 다수 UAV 의 formation flight 와 swarm collision avoidance 를 하나의 분산 제어 프레임워크로 통합한 IEEE Transactions on Cybernetics 발표. Formation controller 는 consensus 기반으로 각 UAV 가 이웃의 상대 위치·속도만으로 의도된 대형 (V-shape 등) 에 수렴 — fixed topology 와 switching topology (통신 단절 포함) 모두에서 수렴 증명 및 convergence rate function 도출. Collision avoidance controller 는 starling bird 의 shadow-projection 메커니즘에서 영감 — 미지의 동적 장애물 회피 + 군집 내 충돌 방지를 3개 가속도 항 ($a_{i1}, a_{i2}, a_{i3}$) 으로 구현. 두 컨트롤러 간 분산 전환 (각 UAV 가 독립적으로 장애물 감지 시 전환) 으로 전체 시스템 안정성 보장. 11대 UAV 시뮬레이션으로 효과성 입증.

Introduction: 연구 동기 클릭하여 자세히 ▸
UAV 다수 운용은 단일 UAV 대비 효율성·강건성 향상 — 정밀 농업, 재난 구호, 긴급 통신, 화물 운송 등. 기존 접근은 formation (대형 유지) 과 swarm (개체 자율 지능) 을 분리 처리. Formation 은 V-shape 등 집단 이점 (공기역학, 에너지 절감) 을 제공하지만 개체 자유도 제한. Swarm 은 개체 자유도 극대화하지만 엄격한 대형 불가. 본 논문은 두 모드를 통합하여 환경에 따라 자유 전환하는 분산 프레임워크를 제안 — starling bird 에서 영감.
Related Works: 관련 연구 클릭하여 자세히 ▸
Formation 제어는 consensus-based (Dong 2015, Ge 2017, You 2011), leader-follower (Liang 2016, You 2019), virtual structure (Li 2008, Ren 2004), artificial potential field (Yu 2011, Chen 2016) 의 4 흐름. Swarm 은 PSO (Bonyadi 2016, 2020), ant colony (Fahy 2019), Reynolds flocking (1987), Vásárhelyi (2018) 의 진화적 배치. Formation + obstacle avoidance 통합은 Wen (2019), Shi (2019) 가 artificial potential field 로 정적 장애물 처리, Olfati-Saber (2002) 가 graph rigidity 기반 분할. 그러나 동적 장애물 + switching topology 를 동시에 다룬 연구는 부재.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
UAV 를 second-order discrete-time system으로 모델링 (위치 + 속도). 두 컨트롤러: (1) Formation controller — 각 UAV $i$ 가 이웃 $j$ 와의 상대 state 차이 $(\xi_j - \xi_i) - (f_j - f_i)$ 에 feedback matrix $K$ 를 곱하여 제어 입력 산출. Fixed topology 에서 Theorem 1 (수렴 조건), switching topology 에서 Theorem 2 (jointly connected 가정 하 convergence rate function $o(t) = s_1 s_2 \gamma^n$). (2) Collision avoidance controller — starling 영감의 3 항: $a_{i1}$ (장애물 반발), $a_{i2}$ (이웃 속도 매칭 + shadow projection 기반 밀도 최소 방향), $a_{i3}$ (내부 안전 거리 반발). 각 UAV 가 장애물 감지 시 독립적으로 모드 전환.
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
11대 UAV, 2D 시뮬레이션, V-shape formation. (1) Fixed topology: 무작위 초기 상태에서 V-shape 신속 수렴, 속도 oscillation → 합의. (2) Switching topology: 4 time slot 주기, 각 링크 최대 2 slot 단절. V-shape 수렴하되 trajectory 상이 (topology 변동 영향). (3) Collision avoidance: V-formation 비행 중 동적 장애물 침입 → 일부 UAV 가 collision avoidance 전환 → 장애물 회피 → formation 복귀. Aggregation coefficient 가 회피 중 peak 후 formation 복귀 시 안정 — 전체 프레임워크 안정성 입증.
Discussion: 결과의 해석 클릭하여 자세히 ▸
본 프레임워크의 핵심 가치는 formation 의 에너지 효율과 swarm 의 유연성을 하나의 분산 시스템에서 결합. Switching topology 에서의 convergence rate function 이 기존 연구에 없던 정량적 수렴 속도 예측 제공. 한계: (1) particle model 이라 실제 UAV 동역학 (특히 고정익·flapping-wing) 미반영, (2) 시뮬레이션 전용, (3) 장애물 감지 구체적 방법 미명시. FWAV 관점: 저자가 multirotor 를 가정하고 "fixed-wing UAV 는 physical dynamics 제약으로 adaptation 필요" 라고 직접 언급 — FWAV 는 hover 불가 + unsteady aerodynamics 라는 더 강한 제약이 있어 본 framework 의 직접 적용이 불가하며, FWAV 전용 formation/swarm 연구가 필요.
Conclusion: 최종 요약 클릭하여 자세히 ▸
본 논문은 다수 UAV 의 formation flight 와 swarm collision avoidance 를 통합하는 분산 제어 프레임워크를 제안. Second-order system 모델 + consensus-based formation controller (fixed · switching topology 수렴 증명 + convergence rate function) + starling-inspired collision avoidance controller (동적 장애물 회피 + 군집 내 충돌 방지). 분산 모드 전환으로 단일 UAV 실패가 전체 시스템에 영향 없음. 11대 UAV V-shape 시뮬레이션으로 효과성 입증.
