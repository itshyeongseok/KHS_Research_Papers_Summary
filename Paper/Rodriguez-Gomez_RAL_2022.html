Free as a Bird: Event-Based Dynamic Sense-and-Avoid for Ornithopter Robot Flight
Tier 0 — 핵심
Juan Pablo Rodríguez-Gómez, Raul Tapia, Maria del Mar Guzmán Garcia, Jose Ramiro Martínez-de Dios, Anibal Ollero
IEEE Robotics and Automation Letters, Vol. 7, No. 2, April 2022, pp. 5413–5420 · DOI: 10.1109/LRA.2022.3153904
논문 요약
본 letter는 대형 ornithopter 최초의 event 기반 동적 sense-and-avoid 기법을 단일 저비용 컴퓨터 + 단일 DAVIS346 event camera로 완전 onboard 실행. Time Filter(Surface of Active Events) · corner detection · ABMOF optical flow · 비동기 clustering을 통한 event-by-event 처리로 플랫폼 적재 예산 내에서 250 Hz 제어 루프 달성. 기하학적 충돌 위험 평가기(safety-volume vs. obstacle-sphere)가 tail-deflection 반응 법칙을 구동하고, flapping-wing 선형화 모델로 보정. GRVC E-Flap(1.5 m wingspan, 510 g)에서 검증: 검출 정확도 91.7%, 평균 동적 장애물 회피율 89.7%(실내/야외 통합, 야외 일반 92.0% / 어두운 환경 85.3%). 저자들이 아는 한 flapping-wing 로봇용으로 설계·검증된 최초의 event 기반 장애물 회피 기법으로, 동적 침입자 대응이 필요한 FWAV waypoint 임무의 인용 기준 baseline.

Introduction — 연구 동기 클릭하여 자세히 ▸
Ornithopter는 민첩성·에너지 효율 flapping-gliding 모드·다회전익 대비 감소된 충돌 위험으로 R&D 주목받고 있으나, flapping 진동과 엄격한 페이로드 예산이 인지·제어를 offboard로 유지시킴. 본 letter는 더 어려운 미해결 서브 문제 — 예측 못 한 동적 장애물의 onboard 회피 — 를 event camera의 µs 해상도·~120 dB HDR·motion-blur 강건성과 단일 저비용 컴퓨터의 event-by-event 처리로 공략. 기여는 flapping-wing 로봇용으로 설계·검증된 최초의 event 기반 동적 장애물 회피, GRVC E-Flap에서 250 Hz로 폐루프 닫음.
Related Works — 관련 연구 클릭하여 자세히 ▸
반응 장애물 회피는 map-based와 map-less 분기로 나뉨; 본 연구는 map-less 라인. 기존 ornithopter 인지 (refs [15]–[17])는 단안·stereo 카메라 사용했으나 처리를 offboard로 유지 또는 시나리오 제한. quadrotor용 기존 event 기반 동적 회피 방법 (refs [8]–[10])은 dual event camera·강력한 임베디드 컴퓨터·호버링 또는 ≤1.5 m/s 비행 요구 → ornithopter에 직접 탑재 불가. Table I이 비교 요약하고 본 설계 동기 부여.
Method — 새로운 접근 방법 클릭하여 자세히 ▸
파이프라인은 2개 모듈. (1) 동적 객체 모션 추정 — Surface of Active Events 상의 Time Filter, *eFast event corner detector, 적응 ABMOF optical-flow 단계, cluster당 running 평균 flow 유지하는 event-by-event clusterer를 chain. (2) 충돌 위험 평가 + Tail 제어 — 로봇을 2W×2H 안전 부피로, 장애물을 반경 R'=R+b 구로 근사, 깊이 의존 기하로부터 허용 각도 ψ*·θ* 산출, 반응 법칙과 flapping-wing 선형화 모델 보정을 결합한 tail deflection u = u_react + Δu_model 명령. ASAP 패키징이 250 Hz 루프 overflow 없이 유지.
Experiment — 실험 방법과 결과 클릭하여 자세히 ▸
검증은 GRVC E-Flap (95 cm 길이, 1.5 m wingspan, 510 g, 최대 520 g 페이로드) + Khadas VIM3 + 무게 trim된 DAVIS346 (FoV 68°×53.5°) 사용. 3개 장애물 — Small Box·Stuffed Toy·FitBall — 을 0.5–6 m 거리에서 발사. 검출: 91.7% 정확도, 95.1% precision, 88.5% TPR, 4.2% FPR, 모션 방향 11.2° RMSE. 회피: 실내 90.7%, 야외 일반 조명 92.0%, 야외 어두움 85.3% — 평균 헤드라인 89.7%. 다중 장애물 시나리오는 cluster 병합으로 74.2%로 감소.
Discussion — 결과의 해석 클릭하여 자세히 ▸
Event camera가 flapping 진동 하 frame 기반 카메라 대비 우수함을 검증, event-by-event 처리가 지연 critical 설계 선택지로 식별. 단일 카메라 + 단일 저비용 컴퓨터로 ornithopter 페이로드 적합 + quadrotor급 검출 도달 충분. 남은 한계는 tail 제어 underactuation·다중 장애물 cluster 병합·어두운 조명·τ trade-off·보수적 안전 inflation·정적 장애물 지원 부재에 집중 — 각각이 사용자 연구가 의도적으로 공격할 수 있는 후보 갭.
Conclusion — 최종 요약 클릭하여 자세히 ▸
본 letter는 대형 flapping-wing 로봇용 최초의 event 기반 장애물 회피 시스템을 제공, 실내·야외에서 평균 89.7% 회피 성공으로 검증, 단일 카메라·단일 컴퓨터 onboard 스택이 250 Hz 폐루프 닫음. 향후 연구는 다른 민첩 로봇으로의 일반화와 완전 sense-and-avoid 스택을 위한 map 기반 정적 장애물 회피 통합을 명시적 타겟 — 사용자 waypoint 임무 연구가 자체 기여를 주장할 수 있는 정확한 방향.
