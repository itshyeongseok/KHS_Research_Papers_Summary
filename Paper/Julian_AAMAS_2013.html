Cooperative Control and Modeling for Narrow Passage Traversal with an Ornithopter MAV and Lightweight Ground Station
Ryan C. Julian, Cameron J. Rose, Humphrey Hu, Ronald S. Fearing
Proc. of the 12th International Conference on Autonomous Agents and Multiagent Systems (AAMAS 2013), May 6–10, 2013, Saint Paul, MN, USA
논문 요약
이 논문은 13 g ornithopter MAV (H2Bird) 와 lightweight ground station 간 cooperative visual servoing 을 통한 좁은 통로 통과 시연을 보고. H2Bird 는 26.5 cm wingspan, clap-fling wing, tail rotor + elevator 로 yaw/pitch 제어, onboard IMU + quaternion PID 로 자세 안정화. Ground station 은 BeagleBoard (1 W) + USB 카메라로 particle filter 기반 실시간 2D pose estimation 수행, 추정 위치로부터 PID heading command 를 radio 전송. Dubin's car + 1차 yaw 동역학으로 시스템 모델링, Monte Carlo 시뮬레이션으로 backwards-reachable set 예측 → 실험 결과 중앙부 80%, 가장자리 50% 성공률로 모델 정합. FWAV cooperative guidance 의 초기 실증 사례로, sub-20 g 급 flapping-wing 의 외부 센서 의존 cooperative navigation 의 가능성과 한계를 정량적으로 제시.

Introduction: 연구 동기 클릭하여 자세히 ▸
10 g 급 MAV 의 전력·크기·중량 제약이 onboard sensing·computation 을 심각히 제한하여, flapping-wing MAV 는 payload 감소로 더 엄격한 제약을 받음. 지상 차량은 이동성은 낮지만 크기 제약이 완화되어 더 많은 computing power 보유 → 이종 로봇 간 협업의 기회. 기존 연구는 고수준 플래닝·큰 vehicle·GPS/motion capture 의존에 국한. 본 연구는 13 g ornithopter + 경량 ground station 의 cooperative visual servoing 으로 좁은 통로 통과를 시연하며, millirobotic 규모에서 협업의 가치를 실증.
Related Works: 관련 연구 클릭하여 자세히 ▸
관련 연구는 3 흐름: (1) Flapping-wing MAV 제어/모델링 — 비선형 동역학 단순화 (주기 평균, 선형 저차원 모델), DelFly 고성능 플랫폼, Baek 의 자율 target seeking. (2) MAV guidance/navigation — 외부 카메라 고도 제어, onboard 카메라 장애물 회피, GPS/motion capture 의존 fixed-/rotary-wing. (3) Cooperative control — UGV 간 visual servoing (Hyams, Jung, Nebot), UAV-UGV 분석적 모델 (Luo, Mehta), 대형 UAV-UGV 협업 (Rudol), 쿼드로터 군집 항법 (Stirling). 모두 kg 급 이상 vehicle 또는 분석적 탐색에 국한 — sub-20 g flapping-wing + 경량 ground station 의 cooperative guidance 는 본 연구가 첫 사례.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
시스템은 H2Bird ornithopter (13 g, 26.5 cm wingspan) + BeagleBoard 기반 ground station (1 W)의 2-agent 구성. H2Bird 는 Silverlit i-Bird 파워트레인 + clap-fling wing + tail rotor/elevator + ImageProc 2.4 (40 MIPS MCU, 6-DOF IMU, 802.15.4 radio, VGA camera), onboard quaternion PID 자세 제어 (300 Hz 내부 루프). Ground station 은 USB 카메라 + particle filter 기반 2D pose estimation (Gaussian transition + ε-random uniform + naïve background subtraction), heading command 를 10 Hz 외부 루프로 radio 전송. 시스템 모델은 1차 yaw 동역학 + Dubin's car 로 구성, system identification 으로 파라미터 결정.
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
3 단계 검증: (1) System identification — 90° step input 응답으로 yaw model 파라미터 결정 (K=0.95, R=0.62, rise time 1.4초), 최소 회전 반경 1.07 m 산출. 카메라 latency 40 ms, pose estimation 12.5 ms, radio 25 ms 측정. (2) Monte Carlo 시뮬레이션 — 카메라 시야 내 10 cm 격자 × 40 trial/점, backwards-reachable set 예측. 중앙부 100% 성공 영역 존재, 시야 삼각형 가장자리에서 성공률 감소. (3) 실험 80 trial — 시야 평면 가장자리 60 trial + 중앙 20 trial. 중앙부 80%, 가장자리 50% 성공률 — Monte Carlo 예측과 정합.
Discussion: 결과의 해석 클릭하여 자세히 ▸
본 연구의 핵심 의의는 sub-20 g flapping-wing MAV 의 cooperative guidance 를 처음 실험적으로 시연한 점. 단순 모델 (1차 yaw + Dubin's car) + particle filter 의 조합이 경량 하드웨어 (1 W BeagleBoard) 에서도 실효성 있는 협업 항법을 가능하게 함. 그러나 2D 추적 (깊이 정보 부재), naïve background subtraction 의 취약성, 10 Hz 외부 루프의 latency, 수동 발사 등이 성능 상한을 제한. FWAV cooperative control 의 초기 baseline 으로서 역사적 가치가 있으며, 이후 연구 (DelFly 자율, E-Flap cooperative) 의 방향을 제시.
Conclusion: 최종 요약 클릭하여 자세히 ▸
본 연구는 13 g ornithopter MAV (H2Bird) + 경량 ground station (1 W BeagleBoard) 의 cooperative visual servoing 으로 좁은 통로 통과를 시연. System identification 기반 단순 모델 (1차 yaw + Dubin's car) 이 Monte Carlo 시뮬레이션과 실험에서 정합하여 cooperative 시스템 성능의 저비용 예측 가능을 입증. 향후 millirobotic ground vehicle (OctoRoACH) 에 ground station 배포, 더 복잡한 multi-agent 시스템으로 확장을 계획.
