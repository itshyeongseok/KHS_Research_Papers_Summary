UAV-CodeAgents: Scalable UAV Mission Planning via Multi-Agent ReAct and Vision-Language Reasoning
Oleg Sautenkov, Yasheerah Yaqoot, Muhammad Ahsan Mustafa, Faryal Batool, Jeffrin Sam, Artem Lykov, Chih-Yung Wen, Dzmitry Tsetserukou
arXiv:2505.07236, May 2025 (preprint)
논문 요약
이 논문은 UAV-CodeAgents — LLM/VLM 기반 multi-agent 프레임워크로, ReAct (Reason + Act) 패러다임을 통해 자연어 지시 + 위성 이미지에서 자율적 UAV 미션을 생성. Airspace Management Agent (AMA) 가 Qwen2.5-72B 로 고수준 계획을, UAV Agent 가 Qwen2.5VL-32B 로 시각 인식 + 실시간 재평가를 수행하며, pixel-pointing 메커니즘 (Qwen2.5VL-7B fine-tuning, 9,000 위성 이미지) 으로 언어 참조 객체를 픽셀 좌표로 정밀 접지. 화재 탐지 case study 에서 temperature 0.5 설정 시 93% 성공률, 평균 96.96초 미션 생성 시간 달성. smolagents 프레임워크 기반 모듈형 설계로 agent 동적 추가/제거·이종 모델 배치·sim2real 전환을 지원하며, UAV 자율 미션 플래닝에 LLM/VLM 을 체계적으로 적용한 최신 사례.

Introduction: 연구 동기 클릭하여 자세히 ▸
자율 UAV 시스템은 환경 모니터링·재난 대응 등 복잡 미션을 수행하지만, 기존 파이프라인은 사전 정의 맵·수동 waypoint·hand-engineered heuristics 에 의존하여 적응성과 확장성이 제한. LLM/VLM 의 발전이 비정형 언어·이미지 입력 기반 추론의 가능성을 열었으나, 기존 프레임워크는 단일 에이전트·폐쇄 환경에 국한. UAV-CodeAgents 는 ReAct 패러다임 + multi-agent 협업 + pixel-level grounding 으로 이 갭을 메우며, 모호한 자연어 지시에서 실행 가능한 UAV 궤적을 생성하는 확장 가능 프레임워크를 제안.
Related Works: 관련 연구 클릭하여 자세히 ▸
관련 연구는 3 흐름으로 분류: (1) 기초 VLM/VLA + 항법 — ViT, CLIP, GPT-4o 등 멀티모달 모델이 AerialVLN·EmbodiedCity 등 UAV 언어 항법의 토대, (2) 인지적 추론 + 미션 플래닝 — CognitiveDrone 의 2-tier VLA (77.2% 성공률), UAV-VLA/VLPA*/VLRR 의 궤적 최적화·NMPC 통합, RaceVLA 의 end-to-end 속도·yaw 예측, (3) 확장성·multi-agent·RAG — OpenVLA/MiniVLA 의 오픈소스 생태계, SwarmGPT/FlockGPT 의 LLM 기반 군집 조율, WildfireGPT 의 RAG 기반 산불 분석. UAV-CodeAgents 는 이 3 흐름을 ReAct 반복 추론 + pixel-level 접지 + multi-agent 협업으로 통합.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
시스템은 3 핵심 컴포넌트로 구성: (1) Airspace Management Agent (AMA) — Qwen2.5-72B 기반 중앙 추론 에이전트로 자연어 파싱·위성 이미지 분석·공간 접지 미션 계획 생성, (2) UAV Agent — 할당된 미션을 실행하며 경량 추론으로 실시간 재평가, (3) ReAct loop (Observe→Describe→Reason→Decide→Act) 로 모호한 입력에 반복적 반성·수정. Pixel-pointing 은 Qwen2.5VL-7B 을 9,000 위성 이미지 SFT 로 fine-tune 하여 언어 참조 객체의 픽셀 좌표 추출. 화재 탐지 case study 로 30 RGB 이미지 (도시·산업·산불·복합) 벤치마크 구성, 2D 시뮬레이션 환경에서 waypoint 보간·뷰 crop·GIF 생성으로 UAV 비행 시각화.
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
2 종 실험: (1) 미션 플래닝 성능 — Qwen2.5-72B (AMA) + Qwen2.5VL-32B (UAV Agent) 로 30 화재 이미지 대상 temperature 0.5/0.7 비교. Temperature 0.5 에서 28/30 성공 (93%), 평균 96.96초. Temperature 0.7 은 26/30 성공, 평균 105.29초로 안정성·속도 모두 열위. (2) Pixel-pointing SFT — Qwen2.5VL-7B 을 9,000 위성 이미지로 fine-tune. ponds (76.77 px)~sidewalks (8.52 px) 의 범주별 mean distance + mean coverage 측정. buildings·roads 등 정밀 범주는 낮은 거리 + 안정적 coverage, farmland·driveways 는 넓은 분포 + 높은 coverage → 맥락 인식 접지 입증.
Discussion: 결과의 해석 클릭하여 자세히 ▸
UAV-CodeAgents 의 핵심 의의는 LLM/VLM 을 UAV 미션 플래닝에 체계적으로 적용한 첫 multi-agent 프레임워크라는 점. Temperature 실험은 생성 모델의 stochasticity 가 미션 크리티컬 UAV 조율에 직접적 영향을 미침을 보여주며, 낮은 temperature 의 안정성이 safety-critical 응용에 필수임을 시사. Pixel-pointing SFT 는 일반 VLM 을 aerial 도메인에 특화시키는 비용 효율적 방법을 제시. 그러나 2D 시뮬레이션만 사용, 실제 비행 검증 부재, 물리 엔진 미반영 등 sim2real gap 이 주요 한계. 향후 실제 UAV 군집, 실시간 텔레메트리, 추가 센서 통합이 필요.
Conclusion: 최종 요약 클릭하여 자세히 ▸
UAV-CodeAgents 는 ReAct 패러다임 기반 LLM/VLM multi-agent 프레임워크로, 위성 이미지 + 자연어에서 자율적 UAV 미션을 생성하는 확장 가능 시스템. Temperature 0.5 에서 93% 성공률·96.96초 달성, pixel-pointing SFT 로 aerial 도메인 정밀 접지 입증. 모듈형 아키텍처로 agent 동적 추가·이종 모델·sim2real 전환 지원. 향후 실제 UAV 군집, 실시간 텔레메트리, 추가 센서 통합으로 재난 대응·환경 모니터링의 실환경 배포를 목표.
