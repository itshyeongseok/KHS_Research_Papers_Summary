논문 요약
UAV-CodeAgents는 위성 영상과 자연어 명령으로부터 자율적 UAV 임무 생성을 위해 LLM과 VLM을 ReAct (Reason + Act) 패러다임 하에 통합한 확장 가능한 다중 에이전트 프레임워크이다. 이 시스템은 상위 계획을 담당하는 영공관제 에이전트(Airspace Management Agent)(Qwen2.5-72B)와 시각적 인지를 담당하는 UAV 에이전트(Qwen2.5VL-32B)로 구성되며, smolagents 프레임워크를 통해 연결된다. 9,000장의 위성 영상으로 미세 조정된(Qwen2.5VL-7B SFT) 픽셀 포인팅 메커니즘을 통해 의미적 대상의 픽셀 수준 정밀 위치 파악이 가능하다. 30장의 이미지로 구성된 화재 탐지 벤치마크에서 평가한 결과, 온도 0.5 설정에서 93% 성공률, 평균 96.96초 임무 생성 시간을 달성하였다. 이 연구는 파운데이션 모델을 UAV 자율성에 적용하는 신흥 화류를 대표하며, 날개칧 차량을 포함한 항공 로봇 플랫폼에 LLM 기반 추론을 통합할 잠재적 가능성을 시사한다.

서론 클릭하여 상세 보기
전통적인 UAV 계획 파이프라인은 사전 정의된 지도와 수동 설정에 의존하여 적응성이 제한된다. LLM/VLM 발전은 비구조적 입력에 대한 추론을 가능하게 하지만, 기존 프레임워크는 단일 에이전트 또는 폐쇄형 환경에 머물러 있다. UAV-CodeAgents는 상위 언어 이해와 하위 지리공간 실행을 연결하기 위해 픽셀 수준 그라운딩을 갖춘 다중 에이전트 ReAct 프레임워크를 제안한다.
관련 연구 클릭하여 상세 보기
관련 연구는 세 가지 흐름에 걸쳐 있다: (1) UAV 시각-언어 내비게이션을 가능하게 하는 기초 VLM(ViT, CLIP, GPT-4o), (2) 상위 인지와 하위 제어를 분리하는 인지 추론 시스템(CognitiveDrone, UAV-VLA 계열), (3) 다중 에이전트 조정 및 RAG 기반 도메인 지식 주입을 위한 확장성 프레임워크(SwarmGPT, FlockGPT, WildfireGPT). UAV-CodeAgents는 픽셀 수준 그라운딩과 함께 ReAct 반복적 추론을 통해 세 가지를 통합한다.
방법론 클릭하여 상세 보기
아키텍처는 세 가지 핵심 구성 요소로 이루어진다: 작업 분해와 공간 그라운딩을 위한 Qwen2.5-72B 기반 영공관제 에이전트(AMA), 경량 VLM 추론을 통한 임무 실행을 위한 UAV 에이전트, 그리고 반복적 계획 개선을 위한 ReAct 루프(관찰 → 설명 → 추론 → 결정 → 행동). 픽셀 포인팅은 9,000장의 위성 영상으로 SFT 미세 조정된 Qwen2.5VL-7B를 사용한다.
실험 클릭하여 상세 보기
평가는 5가지 시나리오(도시, 산업, 산림, 복합, 차량 화재)에 걸친 30장의 RGB 이미지로 구성된 화재 탐지 벤치마크를 사용하며, 모호한 자연어 질의로 테스트하였다. 추론에는 Qwen2.5-72B, 인지에는 Qwen2.5VL-32B를 사용하였다. 온도 0.5에서 93% 성공률, 평균 96.96초 임무 시간을 달성하여 온도 0.7을 모두 초과하였다.
논의 클릭하여 상세 보기
낮은 온도(0.5)가 성공률과 실행 시간 모두에서 0.7을 일관되게 초과하며, 임무 핵심적 UAV 조정에서는 결정론적 추론이 바람직함을 시사한다. 모든 평가는 시뮬레이션에서만 수행되었으며, sim2real 격차, 실시간 텔레메트리 통합, 분포 외 입력에 대한 강건성은 인정되었으나 해결되지 않은 상태이다. 벤치마크 규모(30장 이미지)는 일반화 주장을 제한한다.
결론 클릭하여 상세 보기
UAV-CodeAgents는 LLM과 VLM이 ReAct 스타일 추론을 통해 다중 에이전트 UAV 운용을 효과적으로 조정할 수 있음을 보여주며, 모듈라 아키텍처로 93% 성공률을 달성하였다. 이 연구는 LLM 기반 UAV 자율성의 신흥 패러다임을 제시하며, 군집 조정, 실시간 텔레메트리, 다중 센서 통합으로의 확장이 향후 연구 방향을 정의한다.
