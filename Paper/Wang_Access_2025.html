A Comprehensive Review on Sensor Fusion Techniques for Localization of a Dynamic Target in GPS-Denied Environments
Shoude Wang, Nur Syazreen Ahmad
IEEE Access, Vol. 13, pp. 2252–2281 (2025) · DOI: 10.1109/ACCESS.2024.3519874
논문 요약
본 논문은 GPS-Denied Environment (GDE) 에서 Dynamic Target Localization (DTL) 을 위한 multi-sensor fusion 기술의 포괄적 서베이. PRISMA 가이드라인에 따른 체계적 문헌 리뷰로, 2015–2024 발표된 185편의 핵심 논문을 선별·분석하여 4대 fusion 카테고리 — Odometry Fusion (VIO/LIO/VLIO), SLAM Fusion (VI-SLAM, LiDAR-IMU-SLAM, LV-SLAM, LVI-SLAM), Wi-Fi Fusion, UWB-IMU/BLE Fusion — 를 체계적으로 정리. 각 카테고리에서 filter-based (KF, EKF, UKF, PF), optimization-based (graph optimization), 딥러닝 기반 (CNN, LSTM) 접근법의 장단점을 비교하고, dynamic target 유형 (pedestrian, robot, UAV, vehicle) 별 적용 추세를 시각화. 향후 과제로 NLOS mitigation, multi-target positioning, energy efficiency, privacy/security 를 제시. FWAV 관점에서, 본 서베이의 sensor fusion 전략 — 특히 VIO, LIO, UWB-IMU tight coupling — 은 FWAV 의 GPS-denied 환경 자율 비행에 직접 적용 가능한 기술 기반을 제공.

Introduction: 연구 동기 클릭하여 자세히 ▸
GPS 기반 positioning 은 outdoor 에서는 충분하지만, GPS-Denied Environments (GDE) — 실내, 지하, 수중, 밀집 도시 — 에서는 단일 센서로 dynamic target 의 정밀 위치 추정이 불가. Multi-sensor fusion 기술이 핵심 해법으로 부상했으나, 기존 리뷰는 특정 fusion 방식 (e.g., SLAM only) 에 국한되어 DTL 전체를 포괄하는 체계적 synthesis 가 부재. 본 논문은 이 gap 을 메우기 위해 PRISMA 방법론 기반으로 2015–2024 문헌을 체계 분석, 4대 fusion 카테고리 별 기술·알고리즘·성능을 정리하고, dynamic target 유형 별 적용 추세를 제시.
Related Works: 관련 연구 클릭하여 자세히 ▸
GDE 에서의 positioning 기술은 크게 RF 기반 (Wi-Fi, BLE, RFID, UWB, ZigBee) 과 비-RF 기반 (LiDAR, 초음파, 적외선, 카메라, IMU) 으로 구분. 각 기술은 정확도, 비용, 전력, 확장성에서 뚜렷한 trade-off 를 보이며, 단일 기술로는 DTL 의 모든 요구사항 충족이 불가능하여 multi-sensor fusion 이 필연적. 기하학적 방법 (trilateration, triangulation) 과 fingerprinting 방법이 2대 positioning 원리이며, sensor fusion 의 2대 coupling 방식으로 tightly coupled (단일 state vector 에 모든 센서 통합) 와 loosely coupled (개별 estimator 출력 결합) 가 존재.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
본 서베이의 핵심은 GDE DTL 을 위한 sensor fusion 을 4대 카테고리로 체계 분류하고 각각의 기술·알고리즘·coupling 방식을 상세 분석한 것. (1) Odometry Fusion — VIO (Visual-Inertial Odometry), LIO (LiDAR-Inertial Odometry), VLIO (Visual-LiDAR-Inertial Odometry) 로 세분화. Filter-based (EKF, MSCKF), optimization-based (OKVIS, DVIO), deep learning-based (VINet, DeepVIO) 접근법 비교. (2) SLAM Fusion — VI-SLAM, LiDAR-IMU-SLAM, LV-SLAM, LVI-SLAM 의 4개 하위 카테고리. VINS-Mono, ORB-SLAM3, LIO-SAM, FAST-LIO2 등 주요 시스템 분석. (3) Wi-Fi Fusion — Wi-Fi + PDR, Wi-Fi + 카메라, Wi-Fi + BLE 등 결합 기법. (4) UWB-IMU/BLE Fusion — NLOS mitigation 전략 포함, 보행자·로봇·UAV·산업현장 적용.

Discussion: 결과의 해석 클릭하여 자세히 ▸
본 서베이에서 도출된 핵심 과제와 미래 방향은 5가지: (1) Sensor calibration 및 초기화 — multi-sensor 간 정밀 calibration, 효율적 데이터 correlation, robust initialization, 동적 환경 적응이 성공적 fusion 의 선결 조건. (2) System stability — 일부 센서 고장 시에도 시스템 전체 붕괴 방지 (graceful degradation). (3) Energy balance — 고정밀과 저전력 사이의 trade-off, 특히 fast-moving target 에서 critical. (4) Privacy/security — 위치 정보의 보안 취약성, 이기종 장치·네트워크의 보안 아키텍처 부재. (5) Multi-target positioning — 현재 대부분 단일 target 기준, 2+ target 시 성능 저하 불가피. FWAV 관점 에서, VIO·LIO 의 tightly coupled fusion, UWB-IMU 의 NLOS-robust 전략, DL 기반 self-supervised VIO 는 FWAV 의 GPS-denied 자율 비행·indoor navigation 에 직접 적용 가능한 기반 기술.
Conclusion: 최종 요약 클릭하여 자세히 ▸
본 서베이는 GDE 에서 Dynamic Target Localization 을 위한 multi-sensor fusion 기술의 10년간 (2015–2024) 발전을 PRISMA 기반으로 체계 분석한 포괄적 리뷰. 4대 fusion 카테고리 — Odometry, SLAM, Wi-Fi, UWB-IMU/BLE — 를 센서 유형·coupling 방식·알고리즘·dynamic target 유형별로 정리하고, SLAM Fusion 이 가장 광범위한 적용을, UWB-IMU 가 보행자 분야에서 최다 연구를 보임을 확인. 향후 AI 와 sensor fusion 의 수렴이 자율주행·산업 자동화·스마트시티 등에 transformative impact 을 줄 전망. FWAV 연구에의 시사점: 본 서베이에서 정리된 VIO·LIO·UWB-IMU fusion 전략과 NLOS mitigation, DL 기반 navigation 은 FWAV 의 GPS-denied 환경 자율 비행 기반 기술로 직접 활용 가능.
