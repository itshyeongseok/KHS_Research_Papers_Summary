Sticking the landing: Insect-inspired strategies for safely landing flapping-wing aerial microrobots
Nak-seung P. Hyun, Christian M. Chan, Alyssa M. Hernandez, Robert J. Wood
Science Robotics, Vol. 10, eadq3059 (April 16, 2025) · DOI: 10.1126/scirobotics.adq3059
논문 요약
이 논문은 insect-scale FWMAV (Harvard RoboBee, 100 mg) 의 안전한 착륙을 위해 crane fly 영감 compliant leg + adaptive control + insect 모방 trajectory 의 3 모듈을 결합한 첫 통합 framework. Lossy compliant joint (viscoelastic 재료) 가 충격 에너지를 능동 dissipate, leg stance/joint 수/joint placement 3 변수로 설계 최적화. Adaptive controller 는 ground effect 와 model uncertainty 를 보상 — 27 회 호버링 실험으로 ground effect 를 strong (>7%) / weak (4-7%) / weakest (<4%) 3 영역 정량 분류. Pre-impact deceleration trajectory 가 nonzero impact velocity 로 마무리 (insect 모방). 자연 leaf 위 자율 착륙 시연. Zufferey 의 large-scale perching (Nat Comms 2022) 과 대조되는 insect-scale 영역의 safe landing 첫 통합 사례.

Introduction: 연구 동기 클릭하여 자세히 ▸
곤충은 비행과 지상 이동을 일상적으로 전환하며 — 에너지 절감을 위해 효율적 착륙이 필수. 곤충은 (a) hovering·grazing 하는 통제 접근 (꿀벌·호박벌) 과 (b) 가속·crash-landing (모기·stingless bee) 의 다양한 전략을 사용하며, compliant leg 가 충격 흡수 + tarsal 부착 의 핵심 역할. Multi-rotor 의 compliant landing gear 는 잘 연구됐지만 insect-scale FWMAV 영역은 거의 미개척. 본 연구는 RoboBee + crane fly 영감으로 이 갭을 메운다.
Related Works: 관련 연구 클릭하여 자세히 ▸
곤충 착륙 행동 연구 ([3-9]) 가 본 연구의 직접적 영감. Multi-rotor 영역의 compliant landing gear ([10-12]) 가 큰 vehicle 에서 검증됐으나 insect-scale 은 부재. 기존 RoboBee 연구 — perching with iterative learning [41], electrostatic ceiling perching [42], geometric controller [19], DEA 기반 [17] — 가 본 연구의 토대. insect-scale safe landing 의 통합 framework 은 본 연구가 첫 사례.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
방법은 3 모듈: (1) Compliant leg design — crane fly 영감 lossy 다관절 다리, leg stance/joint 수/joint placement 의 3 design parameter. (2) Ground effect quantification — 27 hover 실험 + ground effect ratio G 정의, strong (>7%)/weak (4-7%)/weakest (<4%) 의 3 region 정량 분류. (3) Adaptive controller + landing trajectory — geometric controller [19] 에 adaptive component 추가 (model uncertainty + 외란 보상), 곤충 모방 trajectory (가속 → 감속 → nonzero impact velocity).
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
3 종 실험: (1) Hover 실험 27 회 (H ∈ 0.5-3) 로 ground effect 정량화 — strong/weak/weakest 3 region 분류, adaptive vs nonadaptive controller 비교. (2) Free-fall drop test (3000 fps high-speed video) 로 leg 디자인 변수 (stance/joint 수/placement) 별 CoR·Δx·e 측정 — crash dummy vehicle 사용. (3) 실 비행 leaf-to-leaf landing 시연 — compliant 경사 leaf 표면에 자율 착륙 성공. Motion capture 환경, RoboBee 본체.
Discussion: 결과의 해석 클릭하여 자세히 ▸
Compliant leg + adaptive control + insect 모방 trajectory 의 3 통합이 결정적 — 단독으로는 어느 하나도 안전 착륙 불가. Energy dissipation 이 piezo actuator 보호의 enabler — vehicle lifespan 연장. 한계: 경사면 / 거친 표면 robust 성, 더 큰 impact velocity, scalability, 완전 onboard 자율성. Future: actuated DEA joint 로 self-righting + multimodal locomotion + 능동 leg 제어. Robots for biology — RoboBee 가 곤충 biomechanics 연구의 physical model 역할 가능.
Conclusion: 최종 요약 클릭하여 자세히 ▸
본 연구는 insect-scale FWMAV (RoboBee 100 mg) 의 첫 통합 safe-landing framework을 제시. Crane fly 영감 compliant leg + ground effect 보상 adaptive controller + 곤충 모방 trajectory 의 3 모듈 결합으로 다양 표면 (compliant leaf 포함) 자율 착륙 성공. Energy dissipation 이 piezo actuator 보호로 vehicle lifespan 연장 → 개발 가속. Future: actuated joint, multimodal locomotion, full onboard autonomy.
