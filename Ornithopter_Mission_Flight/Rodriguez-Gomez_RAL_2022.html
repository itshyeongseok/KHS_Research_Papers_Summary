Free as a Bird: Event-Based Dynamic Sense-and-Avoid for Ornithopter Robot Flight
Juan Pablo Rodríguez-Gómez, Raul Tapia, Maria del Mar Guzmán Garcia, Jose Ramiro Martínez-de Dios, Anibal Ollero
IEEE Robotics and Automation Letters, Vol. 7, No. 2, April 2022, pp. 5413–5420 · DOI: 10.1109/LRA.2022.3153904
논문 요약
이 논문은 대형 ornithopter (날갯짓 비행체) 의 동적 장애물 회피를 위한 세계 최초 event camera 기반 sense-and-avoid 시스템을 제안한다. 온보드 자원 제약이 큰 ornithopter 의 특성 (날갯짓 진동·낮은 페이로드·중속비행 3~6 m/s) 을 고려하여 event-by-event 처리 방식으로 250 Hz 응답을 달성한다. Time filter · corner detector · optical flow · clustering 으로 동적 객체를 추적하고, geometry 기반 collision risk 평가 후 tail deflection 으로 회피 기동을 수행한다. GRVC E-Flap (날개폭 1.5 m, 510 g) 에서 indoor/outdoor 검증 — 평균 회피 성공률 89.7%, 검출 정확도 91.7% 로 quadrotor 용 기존 방법으로 해결 불가했던 ornithopter 고유 문제를 처음으로 해결했다.
Introduction: 연구 동기 클릭하여 자세히 ▸
Ornithopter 는 멀티로터 대비 안전성·에너지 효율 등 장점이 있어 R&D 가 늘고 있으나, flapping vibration 과 strict payload 제약 때문에 onboard perception 이 매우 어렵다. 특히 동적 장애물 회피는 빠른 onboard 검출이 필수인데, 기존 ornithopter 연구는 대부분 offboard · motion-capture 기반이라 이 문제를 풀지 못했다. 본 논문은 event camera 의 μs 분해능·HDR·낮은 무게 특성을 활용해 단일 onboard camera 만으로 dynamic obstacle 회피를 구현한 첫 시도이다.
Related Works: 관련 연구 클릭하여 자세히 ▸
Reactive obstacle avoidance 는 map-based / map-less 로 나뉘며 본 연구는 map-less 흐름. 기존 ornithopter perception 연구 ([15]–[17]) 는 단안·스테레오 카메라를 활용했으나 ground-station 처리 또는 hovering 으로 한정되었다. Event-based dynamic avoidance 는 quadrotor 용 ([8]–[10]) 만 존재하며, dual camera + 강력한 컴퓨터 + hovering~1.5 m/s 저속에 한정 — ornithopter 에 직접 적용 불가능. 본 연구가 이 갭을 메운다.
Method: 새로운 접근 방법 클릭하여 자세히 ▸
본 시스템은 두 모듈로 구성된다. (1) Dynamic Object Motion Estimation — Time Filter (SAE 기반) → Corner Detector → Optical Flow (ABMOF) → Clustering 의 event-by-event 파이프라인. (2) Collision Risk Evaluation + Tail Control — geometric safety volume 으로 충돌 임계각 산출 후 tail deflection 으로 회피. ASAP packaging 으로 communication overflow 없이 250 Hz 응답을 보장한다.
Experiment: 실험 방법과 결과 클릭하여 자세히 ▸
GRVC E-Flap (날개폭 1.5 m, 510 g) 에 DAVIS346 event camera + Khadas VIM3 컴퓨터로 검증. 3종 객체 (Small Box, Stuffed Toy, FitBall) 를 0.5~6 m 거리에서 투척. 검출 정확도 91.7%, 회피 성공률 indoor 90.7% / outdoor 92.0% (regular 조명) / 85.3% (dark). 작은 객체·multi-obstacle 에서 일부 성능 저하.
Discussion: 결과의 해석 클릭하여 자세히 ▸
Event camera 의 우월성 입증 — 진동이 큰 ornithopter 환경에서 frame-based 보다 낫다. Event-by-event 처리가 latency 단축에 결정적. 단일 camera + 단일 컴퓨터 접근으로 페이로드 제약 충족. 한계: tail control 의 underactuated 특성, multi-obstacle cluster merge, dark 조명 noise, static obstacle 미통합.
Conclusion: 최종 요약 클릭하여 자세히 ▸
세계 최초 event-based obstacle avoidance for large-scale flapping-wing robots. Indoor/outdoor 검증, 평균 회피 성공률 89.7%, single camera + single computer + 250 Hz 처리 달성. 향후 다른 agile robot 검증 + static obstacle 통합 sense-and-avoid 시스템 개발이 future work 로 제시된다.
